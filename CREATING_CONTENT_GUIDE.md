# 📝 Creating Your First Content in Sanity Studio

## ✅ What You're Seeing is Normal!

When you open `/admin`, you'll see all the content types in the sidebar, but they'll show **"No documents"** or empty lists. This is expected - you need to create your first content!

## 🎯 How to Create Content

### Step 1: Choose a Content Type
In the left sidebar, click on any content type (e.g., "Team Members", "Partners", "Blog Posts")

### Step 2: Click "Create" Button
- Look for a **"Create"** or **"+"** button (usually at the top right or in the empty state)
- Click it to start creating a new document

### Step 3: Fill in the Fields
- Fill in the required fields (marked with *)
- Optional fields can be left empty
- Use the rich text editor for content fields

### Step 4: Publish
- Click **"Publish"** button (top right) to make it live
- Or save as **"Draft"** to work on it later

## 🚀 Quick Start: Create Your First Team Member

1. **Click "Team Members"** in the sidebar
2. **Click "Create"** button
3. **Fill in:**
   - Full Name: "John Doe"
   - Role/Position: "Executive Director"
   - Department: Select from dropdown
   - Photo: Upload an image
   - Biography: Write a short bio
   - Display on Team Page: ✅ (checked)
4. **Click "Publish"**

## 📋 Recommended Order to Create Content

### Priority 1: Site Settings (Singleton)
1. Click **"Site Settings"** (this is a singleton - only one exists)
2. Fill in:
   - Organization Name
   - Contact Email
   - Contact Phone
   - Social Media Links
   - Logo
3. **Publish**

### Priority 2: Team Members
1. Create 3-5 team members
2. Add photos, roles, and bios
3. Set "Display on Team Page" to true

### Priority 3: Partners
1. Create partner organizations
2. Upload logos
3. Add website URLs
4. Set "Active Partner" to true

### Priority 4: Programs
1. Create your main programs/initiatives
2. Add descriptions, images, and impact metrics
3. Set status to "Active"

### Priority 5: Blog Posts
1. Create 2-3 sample blog posts
2. Add featured images
3. Write content
4. Set status to "Published"

## 🔍 Troubleshooting

### "I don't see a Create button"
- Make sure you're logged into Sanity
- Check that you have write permissions
- Try refreshing the page

### "I see the content types but they're empty"
- This is normal! Click on a content type, then look for the Create button
- The Create button might be:
  - Top right corner
  - In the center of an empty state
  - A "+" icon in the toolbar

### "I can't publish"
- Make sure all required fields are filled
- Check for validation errors (red text)
- Make sure you're logged in with the correct account

## 💡 Tips

1. **Start with Site Settings** - This is a singleton, so create it first
2. **Use Drafts** - Save as draft to work on content over time
3. **Upload Images** - Use the image upload fields to add photos
4. **Rich Text Editor** - Use the toolbar for formatting in content fields
5. **Slugs** - These auto-generate from titles, but you can customize them

## 📸 Adding Images

1. Click the image field
2. Click "Upload" or drag & drop
3. Add Alt Text (important for accessibility)
4. Optionally add a caption

## ✍️ Using the Rich Text Editor

- **Bold**: Select text and click B
- **Italic**: Select text and click I
- **Links**: Select text, click link icon, add URL
- **Lists**: Use bullet or numbered list buttons
- **Headings**: Use the heading dropdown

## 🎉 Once You Have Content

After creating content, you'll see it listed in the content type. Then you can:
- Edit existing content
- Delete content
- Duplicate content
- Filter and search
